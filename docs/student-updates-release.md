# 학생 변경 안내·교수자 시간표·익명 확인 링크

## 적용 범위
- 학생 내 예약: 교수자 대리 예약, 취소, 시간 변경, 장소·안내 변경의 미확인 표시와 변경 내역. 학생 본인 소유권 검사, 교수자 기록 제외, 확인한 이벤트까지만 읽음 처리. 취소 이력 유지.
- 교수자 하단: 시간표 / 예약 관리 / 내 알림 / 더보기. 시간표에서 일정 등록·대리 예약·예약 상세로 연결. 예약 관리는 목록 기본. 기존 알림의 예약 상세 연결 유지.
- 익명 건의: 비공개 기본값 유지. 제출 후 확인 링크 발급, 계정 없이 자기 글·상태·답변 조회. 256비트 난수 토큰의 SHA-256만 저장, 토큰은 URL fragment와 POST 본문으로만 전달. 링크 소지자는 읽을 수 있으므로 공유 금지 안내. 기존 건의는 소급 발급하지 않음.
- 문의는 기존 관리자 담당·소유자 읽음 기능을 유지하고 내 예약에서 미확인 문의를 안내.

## 한계
학생 이메일·휴대폰 푸시는 이번 범위에 포함하지 않음. 접속하지 않는 학생에게 외부 전달을 보장하지 않음. 미참석 제재 정책은 변경하지 않음. 휴지통 건의는 링크 조회도 차단. 확인 링크 분실 시 복구 불가.

## 배포 및 복구
현재 staging 기준 8d39dcab에서 분기. 운영에는 아직 반영하지 않음.
1. CI의 SQLite·PostgreSQL·화면 검사 통과 확인.
2. 백업 및 복구 가능 상태 확인 후 Alembic 0014 적용: 기존 bookings에 기본값 0의 읽음 커서, suggestions에 nullable receipt_hash 및 고유 인덱스만 추가.
3. 배포 후 학생 변경 확인, 교수자 시간표 등록/상세, 비공개 건의 링크 조회 점검.
4. 문제 시 이전 앱 커밋으로 롤백하고 추가 열은 유지. 데이터 손실을 피하려고 DB downgrade는 기본 복구 방법으로 사용하지 않음.

## 이번 검증 결과
- 단위·통합·SQLite 검사 394개 통과. 마지막 스키마 응답 보완 후 관련 21개 재검증 통과.
- Ruff 전체 검사, 변경 JavaScript 문법 검사 통과.
- 슬롯 라벨 10개, 평일 달력 7개, 일정 입력 36개, 스크롤 3개 및 캐시 회귀 검사 통과.
- 로컬 Chromium 실행 제한으로 실제 브라우저·PostgreSQL 검사는 PR #71의 GitHub CI에서 수행한다.
- 첫 전체 검사: 583개 통과, 6개 실패. 제출 완료 화면의 공개 게시판 연결을 복원하고, 시간표 기본 진입에 따른 mock 설치 후 새로고침 및 최신 마이그레이션 기대값을 수정했다. 최종 결과는 PR의 최신 CI 참조.
- 배포 전 Neon 사본: br-cold-lake-aza4cxum (staging 부모, compute 없음). 실제 복원 훈련은 미실행.
- 승인된 배포 대상은 Render classbridge-staging과 Neon staging이다. PR 병합 후 수동 배포하며 /healthz, /readyz, DB 버전 0014 및 배포 커밋을 확인한다.
