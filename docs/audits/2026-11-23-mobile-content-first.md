# 모바일 핵심 내용 우선 배치

## 승인과 범위

2026-11-23 사용자 승인: 학생·교수·관리자 개선안 수정, 테스트, staging 배포.
11/17의 모바일 달력형 기본 및 긴 공지 펼침 결정을 이번 승인으로 변경한다.
학생 모바일 최초 기본은 목록형이며 사용자별 마지막 선택을 같은 브라우저에 저장한다.
공지는 학생 화면에서 접어서 시작하고 명시적으로 펼친 공지 버전을 같은 브라우저에 기억한다.
기기 간 동기화는 없으며 저장소 사용 불가 시 화면 동작은 계속한다.

## 동작

- 공통 모바일 헤더·제목·여백 축소, 44px 터치 영역 유지.
- 학생: 선택일의 가능 상담 및 내 예약 먼저, 다른 일정은 펼쳐 보기. 다른 예약 가능 날짜는 목록 아래에 배치.
- 시간표: 지난 시간과 마감 구분 유지. 최초 달력에서는 일정 시작 시간으로 내부 스크롤, 이후 조작 위치 보존.
- 예약 관리: 전부 조회 성공·0건일 때만 빈 요약. 실패 항목 구분, 오늘 예약 직접 이동 유지.
- 알림: 전경에서 60초 갱신 및 복귀 갱신. 상세창·입력 중 갱신 중단. 오류 시 기존 내용과 재시도 유지.
- 메뉴: 모바일 하단 메뉴 중복 숨김, 그룹 안 목적지 직접 접근. PC 드롭다운 유지.
- 설문: 종료 문구 모순 수정, 참여 가능한 항목 우선, 지난 내역 접기. 익명 안내는 상세 화면에 유지.
- 개인 설정: 요약 비활성 시 시각 입력 비활성화, 값 보존.

## 검증 기준

360×640, 384×640, 390×700, 412×700에서 세 역할 테스트.
학생 첫 예약 카드, 교수·관리자 첫 예약 요약, 첫 알림이 하단 탭 위에 표시되어야 한다.
빈 요약/일부 실패/업무 있음, 보기·공지 기억, 메뉴 단일 탭 이동, 갱신 간격·필터·스크롤·모달·경로 변경 검증.
전체 기존 CI(단위·통합·PostgreSQL·E2E)와 권한 테스트도 통과해야 한다.
