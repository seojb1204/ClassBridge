# 상담 일정 입력과 관리

- 메뉴는 아이콘과 이름을 함께 표시하고 선택한 메뉴를 강조합니다.
- 상담 시간 등록은 날짜·시작·종료에 자유 형식을 받습니다. `11 20`, `11/20`, `11월 20일`, `1120`, `2026-11-20`을 해석합니다. 연도 생략 시 올해이며 지난 날짜를 다음 해로 넘기지 않습니다.
- `10 00`, `1000`, `10시`는 오전 10시입니다. 1~6시는 오후로 해석하고 12시는 낮입니다. 입력 양식은 오전 8시~오후 6시 범위만 받으며 7시, 불가능한 분, 종료 역전은 거부합니다. 기존 저장된 시간과 API 형식은 유지합니다.
- 한 문장 입력 예: `11월 20일 3시~6시`. 입력 내용 적용 후 설정을 확인하고 등록 미리보기를 누릅니다. 해석만으로 저장되지 않습니다.
- 반복 방식은 이번 날짜만 또는 같은 일정으로 매주 등록입니다. 총 몇 주에는 첫 날짜가 포함되며 최대 26주입니다. 확정 전에 실제 생성 날짜, 상담 개수, 겹침을 보여줍니다.
- 예약 가능한 상담 일정은 현재 운영 설정의 예약 가능 기간 안에서 서버가 예약 가능하다고 판단한 시간을 날짜별로 요약합니다. 가까운 3개 날짜와 전체 일정 펼치기를 제공합니다. 버튼은 해당 주·날짜로 이동합니다. 단체 상담도 시간 하나로 셉니다.
- 취소된 시간은 기본적으로 숨기며 ‘취소된 상담 시간 보기’로 조회합니다. 본인이 등록한 취소 시간이고 예약 이력이 전혀 없을 때만 삭제할 수 있습니다. 관리자는 등록자에 관계없이 빈 취소 시간을 삭제할 수 있습니다. 예약 취소·변경 이력도 삭제를 막습니다. 영구 삭제 확인 후 서버가 조건을 다시 검사하고 삭제 작업 이력을 남깁니다.

## 검증과 복구

브라우저 검사에는 입력 해석 경계, 반복 미리보기, 일정 이동, 취소·삭제, 기존 예약/설문/권한 흐름을 포함합니다. 예약 이력 보호와 등록자 권한은 통합 테스트, 동시 삭제는 PostgreSQL 테스트로 검사합니다. 실제 운영 예약을 생성하거나 삭제하여 시험하지 않습니다.

DB 스키마 변경과 새 외부 서비스는 없습니다. 화면 문제 발생 시 직전 배포 `392132944db1f105cde50e2b9e36e14570b9fc98`로 복구할 수 있습니다. 사용자가 확정한 영구 삭제는 코드 복구로 되돌릴 수 없으며 같은 시간을 새로 등록해야 합니다.
