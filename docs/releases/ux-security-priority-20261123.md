## 변경
- **익명 건의 (A-1·2)**: 비로그인 건의는 비공개만 허용(서버 403 `guest_public_forbidden`, 화면에서 공개 선택 제거). 로그인 학생은 계정 경로(`POST /api/suggestions`)로 공개 게시 가능하며 작성자 계정은 저장하지 않는다. 비로그인 속도 제한 키는 `X-Forwarded-For`의 오른쪽 끝 `TRUSTED_PROXY_HOPS`(기본 1)번째 값. 익명 건의 화면에 로딩 문구.
- **모바일 첫 화면 (B-6)**: 학생 예약 화면에서 수동 새로고침 줄 제거(30초·포커스·탭 복귀 자동 갱신은 유지, 실패 시만 안내), 예약 방법 안내를 달력 아래로. 교수자·관리자 시간표는 휴대폰에서 '공지·예약 가능한 날짜' 패널을 닫힌 상태로 시작(PC는 열림 유지), 상단 버튼 2개를 한 줄로. 390×844 기준 달력 시작 위치: 학생 764→560px, 교수자 863→445px.
- **일정 칸 (B-7)**: PC 30분 칸의 둘째 줄 잘림 해소(한 줄 배치). 모바일 축약 라벨을 범례와 같게(학생 '예약 가능', 교수자 '상담 가능'). 한글 단어 중간 줄바꿈 최소화.
- **상담 통계 (B-8)**: 집계 기간을 '지난 N일 + 앞으로 14일'로 확장. 다가오는 예약이 '전체 예약 0 / 예약 중 0'으로 보이던 문제 해결. API에 `upcoming_days` 추가(기존 필드 유지).
- **역할별 UI (C)**: 메뉴 그룹 ▾ 표시, PC 인라인 등록 양식 제거(등록은 '+ 일정 등록' 한 경로), 상담 자료 다운로드를 제목 아래로, 작업 이력 한글화·작업자 이름, 계정 검색·역할 필터, 건의 필터 중복 제거, 한 페이지일 때 페이지 이동 숨김, 개인 설정 세로 배치, 개발자 문의함을 운영자 전용 구역으로, 학생 건의 페이지 제목 통일, 설문 카드에 요약·마감 표시, PC 날짜 버튼 폭 제한.
