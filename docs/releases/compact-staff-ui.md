# 교수자 UI 정리 (2026-11-17)

- 달력형 주간 시간표는 PC/모바일 모두 유지한다. 기존 목록·일간 전환과 예약 처리 API도 유지한다.
- 교수자 상단 메뉴는 예약 관리 / 상담 정보 / 설문·의견 / 관리 그룹으로 묶는다. 권한과 기능 플래그로 항목을 여전히 제한한다. 내 알림은 상담 정보 그룹과 알림 벨에서 접근한다.
- 활동 기록은 PC 5열 한 행(활동 시각, 예약자, 상담 일정, 활동, 상세), 모바일은 라벨 카드다. 최신 기록 생성 순서를 유지하며 이전 기록 추가 조회·필터·새로고침을 보존한다. 처리자/기록 내용은 상세에서 열람한다.
- 예약된 시간만 연녹색 #E5F1E7, 글자 #315B42로 표시한다. 미설정 빈 시간과 예약 가능한 시간의 기존 색은 바꾸지 않는다.
- 공지의 열린 기본값을 그대로 유지한다.
- 스키마/권한 정책/운영 데이터 변경 없음. 되돌리기는 이전 UI 커밋 재배포로 가능하다.

검증: 로컬 lint/JS 회귀/단위·통합 테스트, CI PostgreSQL 및 Chromium PC/모바일 뷰포트 검사. 실제 모바일 기기·실제 Google 계정 로그인 화면은 별도 확인이 필요하다.
