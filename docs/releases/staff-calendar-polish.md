# 예약 관리 시간표 개선 (2026-11-15)

- 교수자/관리자 예약 관리에서만 기존 권한 제한 bookings 응답의 신청 이름(없으면 계정 이름)을 슬롯에 합성한다. 학생 공개 슬롯 API는 변경하지 않는다. 취소 제외, 완료/미참석/기간 종료 예약 이름은 남기며 시간과 불가 사유를 함께 표시한다. 텍스트 노드로 출력한다.
- 공지 본문과 교수자 공지/예약 날짜 영역은 기본 펼침. 접기 버튼은 유지한다.
- 별도 `+ 강의 추가` 버튼을 없애고 기존 상담·강의 등록 화면의 강의 탭으로 단일화했다. 달력 빈칸을 눌러 여는 등록도 같은 화면이며 기존 강의 편집은 유지한다.
- 이전 구현은 달력 재그리기마다 3~5개 데이터를 요청하고 교수자 오늘 요약도 반복했다. 선택한 달력 GET만 15초간 메모리에 보관하고 동시 호출을 합친다. 현재 양옆 1주를 사전 읽으며 최대 40항목으로 제한한다. 원격 서비스 지연 자체를 없애는 변경은 아니다.
- 개인정보는 localStorage/IndexedDB/service worker에 저장하지 않는다. 모든 변경 요청 전후와 인증 토큰 변경에 캐시를 비우고, 캐시가 무효화되는 동안의 응답은 다시 읽는다. 실패는 저장하지 않으며 명시적 새로고침과 교수자 30초 갱신을 제공한다. 오래된 교수자 달력 응답이 새 주/다른 보기 화면을 덮지 못하게 버전·경로를 확인한다.

검증: `node scripts/test-calendar-cache.mjs`, `ruff check app tests migrations scripts`, `pytest`, `RUN_E2E=1 pytest tests/e2e`. 로컬 Chromium은 환경의 Unix socket 권한 때문에 시작하지 못했다. 실제 브라우저 검사는 GitHub CI 결과를 별도로 확인해야 한다. 실물 갤럭시/iPhone 및 운영 네트워크 성능은 미측정이다.
