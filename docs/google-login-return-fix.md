# Google 로그인 복귀 오류 수정

2026-11-18 09:24 KST 운영 로그에서 서로 다른 로그인 시도 두 건 모두 같은 코드의 콜백이 302 성공 직후 약 0.2초 내 재실행되어 401이 된 것을 확인했다. Google 비밀키가 틀렸다고 단정할 근거는 없다. 중복 요청을 유발한 정확한 브라우저 내부 동작은 미확정이다.

- 성공 콜백은 세션 쿠키를 담은 no-store HTML 문서를 반환한 뒤 새 페이지 이동으로 홈/설문에 복귀한다. 인증 코드가 있는 URL의 HTTP 리다이렉트 연결을 끊는다.
- 루트 오프라인 처리는 현재 URL로 새 요청을 생성해 이전 이동 이력을 전달하지 않는다. 워커 업데이트는 즉시 활성화한다.
- 코드 교환 실패 화면은 새 Google 로그인을 시작할 링크를 제공한다. 실패를 로그인 성공으로 처리하지 않는다.
- 상태·nonce·서명·권한·세션 검증을 유지한다. DB 변경은 없다.
- 인증 콜백 쿼리를 앱 접근 로그에서 제거하고 Google 오류는 허용한 종류와 상태 코드만 기록한다.

검증: 단위·통합 검사와 실제 Chromium PC/모바일 + 활성 서비스워커 회귀 검사를 실행한다. 브라우저 검사는 1회용 가짜 Google 검증기로 수행하므로 실제 Google 계정으로 사용자의 최종 로그인 재확인은 별도다. 롤백 기준은 8334a6e이며 DB 복원은 필요하지 않다.
