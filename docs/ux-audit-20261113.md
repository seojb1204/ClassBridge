# ClassBridge usability audit, 2026-11-13

Scope: existing functionality and service name retained; production records and notifications are not test fixtures. Visual redesign is a separate change.

## Changes
- Survey permanent deletion: one explicit `아니오` / `예, 영구 삭제` dialog, default focus on No. Names survey and counts responses, warns questions/answers/participation records cannot be recovered. No typed phrase. Existing server authorization, CSRF, trash-only rule and response-count conflict check are unchanged.
- Survey management: one action at a time, success feedback, latest list response wins, recover from request failures.
- Survey responses: required-question summary linked to inputs; inline errors and accessible labels; answers stay entered on validation failure. Optional single-choice/scale answers can be reset to unanswered.
- Common unsubmitted dialogs close on route changes. An already-submitted action is not described as cancelled.

## Cross-service evidence
- Google Forms documents irreversible response deletion followed by a confirmation button, not typing a phrase: https://support.google.com/docs/answer/2917686
- GOV.UK distinguishes destructive final confirmation from ordinary actions; button labels describe outcomes: https://design-system.service.gov.uk/components/button/
- GOV.UK error summary links to affected inputs and focuses the summary: https://design-system.service.gov.uk/components/error-summary/

## Verification boundaries
Local unit/integration run: 351 passed, 34 PostgreSQL tests skipped because no TEST_PG_URL configured. Lint and JS syntax passed. Dedicated browser tests and full CI are recorded separately in the PR, never inferred from source review. Browser default Playwright download returned invalid archives, so installed Chromium is tried through approved execution instead.

Not covered by the synthetic suite: real Google OAuth, real phone/Safari rendering, OS push reception, production mail delivery, every possible state combination. No real production deletion or notification was performed. Broad all-function coverage means the enumerated automated journeys, not a claim that every feature/state was manually exercised.

## Deferred consideration
