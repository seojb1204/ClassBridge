# Android 설치형 웹앱

## 사용 방법

배포 후 Android Chrome으로 기존 ClassBridge 주소를 열고 교수자 계정으로 로그인합니다.
상단 메뉴의 **앱 설치** 또는 **앱 설치 안내**를 누릅니다. Chrome 메뉴의 **홈 화면에 추가 → 설치**도 이용할 수 있습니다.
설치 안내가 바로 나타나지 않으면 Chrome에서 다시 열어 주세요. 카카오톡 내부 브라우저에서는 외부 Chrome을 사용합니다.
홈 화면 아이콘으로 실행하면 전체 예약 목록으로 시작하며, 기존 예약·상담 관리 기능을 이용합니다.
학생은 기존 링크를 그대로 사용합니다. 설치 자체는 권한을 부여하지 않으며 서버가 교수자 권한을 검사합니다.

## 범위와 데이터

- 별도 앱스토어 등록, 유료 서버, DB 변경, 환경변수 추가가 없습니다.
- 휴대폰 푸시 알림은 포함하지 않습니다. Gmail 알림 작업과 별개입니다.
- 인터넷 연결이 필요합니다. 오프라인 예약이나 변경을 접수·대기시키지 않습니다.
- 서비스 워커는 공개 연결 안내 페이지만 Cache Storage에 보관합니다. API 응답·상담 기록·로그인 화면·파일 다운로드는 캐시하지 않습니다.
- 기존 로그인 세션과 브라우저의 일반 저장 동작은 유지합니다. 휴대폰 잠금 및 공용 기기 로그아웃이 필요합니다.
- 앱 화면은 기존 웹 UI와 서버를 공유합니다. 업데이트는 서버 배포로 전달되며 설치된 창을 닫았다가 다시 열면 최신 화면을 불러옵니다.

## 검증 및 배포

기준 커밋: 8724dd57a50b91ef404ba7ce8505944ee514178e (staging).
로컬: 단위·통합 162개, Chromium 브라우저 18개 통과. Ruff 통과.
브라우저 검사는 모바일 설치 안내, 전체 기간 예약 목록, 설치 실행 모드의 교수자 홈(모의 display-mode), 학생 권한, 오프라인 안내, 비공개 API 캐시 미생성 및 재연결을 포함합니다.
실제 Android 설치 대화상자·홈 화면 실행·Google 로그인 왕복은 실제 휴대폰에서 최종 확인해야 합니다. 개발용 로그인 검사와 실제 Google 연동은 다릅니다.

운영 배포는 별도 승인 후 staging에 병합하여 같은 Render 서비스에 적용합니다. 운영 데이터나 Gmail 설정은 변경하지 않습니다.
문제가 발생하면 위 기준 커밋으로 Render 배포를 복구할 수 있습니다. 이미 등록된 서비스 워커는 네트워크 우선이며 앱 파일을 캐시하지 않으므로 이전 웹 화면도 그대로 조회합니다.
서비스 워커까지 완전히 제거하려면 해당 주소의 사이트 데이터 삭제·앱 제거 또는 별도의 해제용 워커 배포가 필요합니다.
