# 교수자 강의와 상담 통합 시간표

- 학생 개인 시간표, 외부 서비스 연동, 알림/메일 발송은 추가하지 않습니다.
- 교수자/관리자가 기존 상담 시간표에서 강의를 추가합니다. 강의명·날짜·24시간 시작/종료·강의실(선택)·같은 요일 총 1~26주 입력입니다.
- 강의는 별도 lectures 테이블에 저장되고, 상담 Slot/Booking 통계에 섞이지 않습니다.
- 강의 시간과 겹치는 신규 상담/대리예약/예약변경은 서버에서 차단합니다. 끝나는 시간과 다음 시작 시간이 같은 경우는 겹치지 않습니다.
- 이미 booked 상담이 있으면 강의 생성/수정을 거부합니다. 기존 예약을 자동 취소하지 않습니다. 빈 상담 Slot은 보존되며 강의 취소 후 다시 기존 예약규칙을 적용합니다.
- 이번 강의만 수정할 수 있고, 삭제는 이번 강의/반복 전체를 선택합니다. 삭제는 cancelled 상태 변경으로 원본을 보존합니다.
- 학생에게 강의명/강의실은 공개하지 않습니다. 학생은 겹친 상담을 '강의 시간'으로 확인합니다.
- PostgreSQL에서 강의쓰기와 상담트랜잭션은 공통 advisory transaction lock을 먼저 획득합니다. SQLite는 운영 동시성 보장 대상으로 간주하지 않습니다.
- 마이그레이션은 추가형입니다. 데이터가 존재하는 경우 downgrade는 거부합니다.

## 사진 인식 검토 (미구현)
현재 외부 OCR 호출/사진 업로드/AI 기능 활성화/CSP 변경 없음. 브라우저 Tesseract.js는 유료 API 없이 가능하지만 표 위치 해석·한글 인식 정확도·WASM CSP와 모바일 메모리를 검증해야 합니다. 사용자가 파일 선택한 뒤 브라우저 내 OCR, 수정 가능한 초안, 사용자가 확인 후 일정 저장 순서가 적합합니다. 이번 버전은 수동 입력입니다.
