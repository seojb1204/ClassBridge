# 교수자·관리자 시간표 간소화 (2026-11-24)

승인 범위: 본문은 주 이동·시간표·플로팅 일정 등록으로 구성한다. 브랜드, 상단 알림과 하단 이동 메뉴는 유지한다. 공지/가능 날짜, 범례, 보기 전환, 사용 안내, 날짜별 인원 표시는 임시 숨김이며 학생 예약 화면에는 적용하지 않는다.

일정 등록은 상담 시간·강의·예약 등록을 한 창에 제공한다. 예약 등록은 이름 필수, 학생 계정 연결 선택이며 날짜·시작·종료·장소를 입력한다. 미연결 예약은 교수자/관리자만 관리하고 학생의 내 예약에는 노출하지 않는다. 학생 계정을 연결하면 기존 예약 제한과 본인 조회 정책을 그대로 적용한다.

직접 예약은 기존과 같은 정확한 상담 구간이면 정원 내 재사용한다. 일부 시간 겹침, 새 상담 칸과 강의 겹침, 지난 시간, 주말, 잘못된 길이와 장소 충돌은 거부한다. 기존 상담이 강의보다 우선하는 정책은 유지한다. 빈 구간에는 상담 칸과 예약·이력·알림을 하나의 트랜잭션으로 저장하며 실패 시 전부 취소한다. PostgreSQL 잠금 및 기존 정원 조건 갱신을 유지한다.

## 데이터 변경과 복구

0015는 bookings.student_id의 NULL을 허용한다. 기존 예약·계정·기록을 수정하거나 삭제하지 않는다. SQLite 테이블 재구성에서는 외래키를 검증하고 다시 활성화한다. 운영 PostgreSQL은 해당 열의 NOT NULL만 해제한다.

미연결 예약이 생긴 후에는 0015 다운그레이드를 거부한다. 데이터 삭제나 가짜 계정 생성으로 우회하지 않는다. 복구 시 NULL을 지원하는 버전에서 UI를 되돌리거나 수정 배포한다. 기존 버전으로 단순 앱 롤백하면 미연결 예약 조회가 누락될 수 있으므로 허용하지 않는다.
